# Confidentialité des données

Ne jamais committer :

- exports Chronotime réels ;
- fichiers HAR ;
- captures d’écran ;
- journaux bruts ;
- cookies ;
- en-têtes d’autorisation ;
- jetons de session ;
- identifiants OAuth ;
- URL internes ;
- données personnelles de calendrier ;
- données internes d’entreprise ;
- noms de collègues, managers ou RH ;
- matricules ou identifiants internes.

Le dépôt doit rester limité à des données d’exemple anonymisées.
